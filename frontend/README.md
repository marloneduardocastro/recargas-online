# Frontend - Venta de recargas

Pantalla Angular para vender recargas y consultar el resumen por operador y vendedor.

```bash
npm install
npm start        # http://localhost:4200 (las llamadas a /api van a http://localhost:8080)
npm test         # pruebas del componente con Vitest
npm run build    # compilación de producción en dist/
```
